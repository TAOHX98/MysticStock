# ☯️ MysticStock 玄学推演系统

基于《洛书》数理与时空干支动态同频映射的纯血离线股票推演引擎。

## ✨ 特性

- 🌌 本土易经内核，完全离线推演
- 📈 梅花易数·洛书数理模型
- ⚛️ 零API依赖，纯代码数学引擎
- 🎯 六步推演算法：股票后天卦 → 时间卦 → 年月动能 → 共振信号 → 日建填实 → 定性定量分析

## 🚀 在线体验

部署在 Streamlit Cloud 上后，可直接通过浏览器访问。

## 🛠️ 本地运行

```bash
pip install -r requirements.txt
streamlit run app.py
```
